# Addressing Mode

Addressing mode specifies the way in which the operand of an instruction is accessed. In 8086 microprocessors, various addressing modes are used to access data in memory or registers. Each mode defines a unique method of specifying operands.

### <mark style="background: #FF5582A6;">IMPORTANT TERMS</mark>

- <mark style="background: #ABF7F7A6;">Starting address of memory segment.</mark>
- <mark style="background: #ABF7F7A6;">Effective address or Offset: An offset is determined by adding any combination of three address elements: displacement, base and index.</mark>
- <mark style="background: #ABF7F7A6;">Displacement: It is an 8 bit or 16 bit immediate value given in the instruction.</mark>
- <mark style="background: #ABF7F7A6;">Base: Contents of base register, BX or BP.</mark>
- <mark style="background: #ABF7F7A6;">Index: Content of index register SI or DI.</mark>
